# 🐍 手勢控制的貪食蛇 | Hand Tracking Snake

## 設計理念

**我的進化版 Snake 改變了原版的哪一個玩法？**

傳統貪食蛇用鍵盤方向鍵控制，本作品使用 **MediaPipe Hand Tracking** 透過 webcam 即時偵測手勢，讓玩家「用手控制」蛇的移動方向。

**玩家需要做什麼新的判斷或操作？**

- 張開手掌：蛇持續前進
- 握拳：蛇停止移動
- 移動手指（食指與拇指的相對位置）：改變蛇頭方向

**MediaPipe 如何影響玩法？**

MediaPipe Hands 提供了即時的21個手部關鍵點偵測。我利用食指指尖(landmark[8])與拇指指尖(landmark[4])的相對位置計算方向向量，取代傳統鍵盤輸入。握拳偵測（四指彎曲）則作為「緊急停止」的安全機制。

**我希望玩家玩完後覺得哪裡和普通 Snake 不一樣？**

最大的不同是「操作感」——從按鍵盤變成真的用手勢控制。玩家不再只是敲擊方向鍵，而是像操控遙控車一樣，透過手部動作直接影響遊戲角色的行為。這種「所見即所得」的沉浸式操控，帶來完全不同於傳統鍵盤操作的遊戲體驗。

此外，**移動食物**增加了策略難度——玩家必須在控制蛇的方向的同時，快速判斷食物的移動趨勢，規劃下一步。

## 🎮 操作說明

| 手勢 | 動作 |
|------|------|
| ✋ 張開手掌 | 蛇前進 |
| ✊ 握拳 | 蛇停止 |
| 👆 移動手指 | 改變方向 |
| 🍎 移動食物 | 每2秒隨機移動 |

## 🚀 部署

本專案使用 Vite + Vue 3 開發，部署至 Vercel。

```bash
npm install
npm run dev    # 開發模式
npm run build  # 構建生產版本
```
